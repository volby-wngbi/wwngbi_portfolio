AI Lab · Case 02

월급계산기

사내 배포 · v1.3.7

일한 만큼 달라지는 월급, 미리 확인할 수 있게 만들었습니다.

재직 중인 회사는 선택적 근로시간제를 운영합니다. 한 달 근무시간이 기준보다 많거나 적은 만큼 월급이 크게 달라지지만, 근로자가 이를 미리 확인할 방법은 없었습니다. 그래서 근태 기록만 불러오면 회사 규칙대로 세전·세후 월급을 계산하는 Mac 앱을 기획해 만들고, GitHub로 사내에 배포했습니다. 동료들의 피드백을 받아 2주 동안 17번 업데이트했습니다.

화면의 금액과 근무시간은 모두 예시 값입니다.

Why

근무시간에 따라 달라지는 월급

선택적 근로시간제는 출퇴근 시간을 자유롭게 정하는 대신, 한 달 합계로 급여를 정산합니다. 월 법정근로시간을 넘기면 초과수당이 붙고, 모자라면 기본급에서 공제됩니다. 그 차이가 큰데도 근로자가 직접 확인할 방법이 없어서, 누구나 쉽게 확인할 수 있는 도구를 기획했습니다.

Before · 명세서가 나와야 알 수 있음

  1. 1근태 시스템에서 날짜별 근무시간을 하나씩 확인
  2. 2이번 달 초과·부족 시간을 직접 계산
  3. 3초과수당·부족 공제·세금은 명세서가 나와야 확인

After · 근태만 불러오면 바로

  1. 1근태 CSV나 스크린샷을 불러오면 날짜별로 자동 입력
  2. 2월 법정근로시간 대비 초과·부족을 분 단위로 계산
  3. 34대보험과 2026년 간이세액표로 세후 월급까지

Process

코드 대신 요구사항과
검수로 만들었습니다

저는 무엇을 계산하고 어떻게 보여 줄지를 정하고, AI가 만든 결과를 실제 명세서와 대조하며 고쳤습니다. 영상 제작에서 PD가 하는 일과 같은 방식입니다.

  1. 01

    웹 개발판으로 먼저 확인

    앱을 매번 새로 만들지 않고, 브라우저에서 바로 바뀌는 웹 개발판으로 화면과 계산을 확인하며 피드백했습니다.

  2. 02

    계산 규칙은 말로 정의

    통상시급, 월 법정근로시간, 야간 가산처럼 회사 급여 규칙을 대화로 정하고, 실제 명세서와 대조하며 틀린 부분을 바로잡았습니다.

  3. 03

    GitHub로 사내 배포

    확정된 버전만 Mac 앱으로 포장해 GitHub 릴리스로 배포했습니다. 동료들은 한 번 설치하면 앱 안에서 새 버전을 받아 자동으로 업데이트합니다.

Rules

선택적 근로시간제 정산을
분 단위로 옮겼습니다

하루가 아니라 한 달 합계로 정산합니다. 월 법정근로시간을 넘긴 인정시간은 1.0배, 그중 실제로 일한 시간과 야간·휴일 근로에는 0.5배를 더하고, 모자란 시간은 기본급에서 공제합니다. 앱의 계산을 그대로 옮겨 두었으니 근무시간을 바꿔 보세요.

  • 월 법정근로시간 = 40시간 × 월 일수 ÷ 7
  • 통상시급 = 연봉 ÷ 12 ÷ 209, 원 미만 올림
  • 연차·공휴일은 일반근로 8시간으로 인정
  • 법정근로를 넘긴 인정시간은 1.0배, 실근로 초과분은 0.5배 가산
  • 야간(22~06시)·휴일 근로는 따로 0.5배 가산
  • 모자란 시간은 통상시급만큼 기본급에서 공제

실제 앱은 이 값들을 날짜별 근태 기록에서 자동으로 모으고, 부족근로 공제와 4대보험, 소득세까지 함께 계산합니다.

Input

근태는 불러오기만

근태 시스템에서 받은 CSV나 근태 화면 스크린샷 여러 장을 한 번에 불러오면, 날짜별로 합쳐 캘린더에 채웁니다.

  1. 1CSV 또는 스크린샷 여러 장 선택
  2. 2OCR로 순서대로 인식하고, 실패한 장이 있어도 성공한 결과는 유지
  3. 3인식 결과를 확인·수정한 뒤 캘린더에 반영
  4. 4날짜를 눌러 일반·실근로·야간을 분 단위로 고치기

Result

사내에서 매달 쓰는 급여 앱

GitHub 릴리스로 사내에 배포했습니다. 동료들은 DMG로 한 번 설치한 뒤, 새 버전이 나오면 앱 안에서 바로 업데이트합니다. 여러 사람의 급여라는 민감한 정보를 다루기 때문에 보안 설계에 가장 공을 들였습니다.

월급계산기 · macOS 앱 · 예시 데이터

급여 대시보드 · 세전·세후 월급과 세부 내역, 계산 근거를 한 화면에

서버 없이 내 Mac에만

계정과 급여 입력값은 AES-GCM으로 암호화해 각 Mac의 앱 저장소에만 둡니다. 다른 사람과 자동으로 공유되지 않습니다.

기본은 금액 숨김

로그인 비밀번호와 별개인 4자리 비밀번호를 입력해야 금액이 보입니다. 다시 열면 금액은 다시 가려집니다.

서명된 업데이트만 설치

새 버전은 전용 키로 서명하고, 앱은 서명과 파일 크기를 확인한 뒤에만 설치합니다.
